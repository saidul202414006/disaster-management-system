All Disaster Events

Basic SELECT — All disaster events with duration (derived attribute)

Basic SELECT
SQL (Oracle Syntax)
SELECT disaster_name, disaster_type, division, district, start_date,
  (end_date - start_date) AS duration_days
FROM DISASTER_EVENT
ORDER BY start_date DESC
